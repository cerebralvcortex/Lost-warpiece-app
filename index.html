Quick fix fast
Repackages the file and converts only the audio track. The picture itself is not re-encoded, so this is typically minutes, not hours — fixes the most common cause of playback FAILING to start (incompatible audio like Atmos/DDP).
Downscale faster than full
Shrinks the picture to 720p and re-encodes it. Use this if the file DOES play but stutters, freezes, or falls behind — that is a sign this device cannot decode the full resolution fast enough, and no sync setting can fix that. Meaningfully faster than a full-resolution conversion since there is far less picture data to process.
Full conversion slow
Re-encodes the video at full resolution, so it is guaranteed to play — but this runs entirely on this device's CPU with no hardware acceleration.
